# Three.js Playground

Small 3D project built with Three.js to explore basic WebGL rendering in the browser.

## Live Demo

https://threejs-playground-theta.vercel.app/

## Features

- 3D primitives (box, sphere, torus)
- Render loop with `requestAnimationFrame`
- Modular structure (core / objects / animations)

## Tech Stack

- Three.js (WebGL renderer)
- JavaScript (ES Modules)
- Vite

## Run locally

```bash
npm install
npm run dev
